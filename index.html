Core Capabilities

Built for dependable event operations

Essential features designed to keep registration flowing without interruptions.

True Offline-First SQLite

Saves all scans to a local device database in atomic transactions. Keep scanning smoothly even with zero mobile signal.

Smart Year-Level Parsing

Automatically calculates 1st, 2nd, 3rd, or 4th+ year levels directly from student ID barcodes based on cohort numbers.

Duplicate Prevention

Prevents double-scanning locally. Multi-device conflicts are stored for review to preserve accurate attendance numbers.

Supabase Cloud Sync

Background batch sync when internet reconnects. Safe RLS policies keep your participant data protected.
